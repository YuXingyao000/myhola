## 复杂度与缺失记录

复杂度沿用现有0.1容差有效性检查：旧733件可计算，新版两组均为0件；新组数值记为N/A，不填0。边数为现有实现的边遍历计数，环复杂度为E−V+2C。
原生合法子集MMD/COV/JSD/LFD/Unique/Novel及等量合法子集结果均保存在CSV中；空子集标null/n=0。
点云指标失败：旧38件；新版last为715件三角化错误+1件指标超时；新版最低val-loss为715件三角化错误+2件指标中断+2件指标超时。全部保留在1000分母。
耗时为本次并发运行的逐件实测。训练量、数据和历史增强差别见[训练记录](../uncond_training_20261018/PLAN.md)。
