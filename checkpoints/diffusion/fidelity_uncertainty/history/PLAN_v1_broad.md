# 单图 B-Rep：忠实重建与合理不确定性的下一阶段计划

> 历史宽泛草案。用户已明确收窄为“新版DPO数据与配对规则 → DPO重训对照 → 几何辅助训练”；本稿不作为执行队列，以[当前计划](../PLAN.md)为准。

## 1. Task

2026-10-23 讨论形成的 v1 计划。目标保持为：**单张图片输入，输出合法、忠实于观测的 B-Rep；对于观测不足的部分允许受约束的合理补全。**

当前优先交付定量评估工具和可比较的基线，再据此决定 DPO 数据改进与冻结 decoder 的几何辅助训练。本次仅编写计划，下面未勾选的项目均未执行；本文不替代实际运行前的完整配置和数据协议。

研究问题：

- 现有 DPO 提升合法率、平均可见一致性后，是否遗漏了小孔槽，是否压缩了同图的合理变化？
- 更强但保持同一 latent 空间的 decoder，能否改善 diffusion 输出，收益是否与 DPO 互补？
- 改进偏好标签、直接监督解码几何，分别解决什么失败机制，收益是否超过同预算继续训练？

## 2. Assumptions

**已核对事实**：

- 当前有效基线为原 1024 维 concat SVR 与其 DPO 5,000 步版本，原 HoLa VAE；不是逐层 cross-attention 模型。
- 全 validation 3,505 件、每图 K=1：合法率 77.72%→88.25%。可见表面误差在共同可测 3,226 件上改善；完整几何 CD 的差值区间仍跨零。
- train 共 46,627 CAD、每图计划 8 候选、固定 42,037 对；每图最多一对。未配对 CAD 仍参加 GT 去噪训练。候选没有在后处理后重新编码。
- 训练候选目录共 373,016 个，上一轮文件扫描有 373,012 份 latent/raw/metrics，4 个中断候选缺 latent；validation100 的 800 个候选完整。执行前重新做 manifest 审计，目录存在不代表所有几何指标可测。
- 现有多候选工具计算全部 raw 点集差异，并分全部/合法子集；没有实现“合法且符合观测”筛选后的可见/遮挡几何变化。
- 冻结 32 维 shared curve + UV best 的 GT roundtrip 为 3,180/3,495，90.99%；原 3,505 分母为90.73%。其 encoder/posterior 已与原 SVR 内嵌 AE 逐张量核对一致。该比例不是单图重建的上限。

**研究假设，尚非结论**：更精确的观测评价能减少错误偏好；冻结 decoder 的几何损失能改善 latent 去噪目标与最终几何之间的不一致；保留多组合理候选可能改善覆盖。这三项需独立验证。

**范围假设**：先固定 DeepCAD 灰模 view0、原相机/尺度/坐标，使用 validation 开发；不将成绩解释为实拍泛化。训练只读 train，test 在方案冻结后使用；ABC 最终子集继续隔离。

**Needs confirmation / 实施前待冻结**：新增细节指标的可见边界定义、容差网格、观测合格阈值、多候选正式运行规模与资源预算、几何损失目标及时间权重。先用已知几何反例确定测量含义和分辨率误差，再固定这些参数；不得根据哪个模型赢来选阈值。此处待定项不妨碍先完善评测协议。

## 5. Processing Protocol

### 阶段 A：完善指标并固定评测协议（当前优先）

1. 复用现有合法性、完整 raw/post 几何、输入轮廓和可见表面指标，不改写旧报告。
2. 扩展统一候选 manifest 与 K>1 观测评估，避免仅支持 `c00` 的旧适配器漏掉其他候选。按第6节补齐观测合格率、同图差异、近重复和可见细节指标。
3. 把候选差异迁移到裁剪后几何的固定采样协议；原 raw 差异继续保留为诊断，不混报。细节指标先完成已知形状和渲染基准验证。
4. 冻结定义、采样/渲染分辨率、阈值网格与汇总方法，生成机器可读 `protocol.json` 后开始正式计算。初版分别报告指标，不合成为一个任意加权总分。

交付：指标说明、实现、行为验证、逐候选/逐图示例和可复现命令。小批量仅验收实现。

### 阶段 B：建立质量与多候选的固定基线

1. 复用原/DPO 各3,505件 K=1 输出，补算新增指标；预先指定 c00 始终作为单次输出，不用候选最优替代。
2. 复用原模型 validation100×8，补齐相同图片、相同 seed 协议的 DPO K=8。c00 仅在协议/来源完全一致时复用。该表明确是固定100件开发子集的结论。
3. 如要对完整 validation 的条件多样性作结论，建议两模型都扩为3,505×8；在查看新增候选结果前固定预算与清单。不能按100件成败挑选扩展对象，也不为凑合法候选重抽。
4. 同时给出 K=1、全部 K 次平均质量、每图合格率和质量条件下的差异。可给固定前缀 K=1/2/4/8 的曲线，保留总采样成本。bootstrap 以 CAD 为聚类单位，不把同图28个候选对当成28个独立对象。

交付：原/DPO质量与多样性对照。先判断是否存在可见细节损失或分布收缩，再决定如何改偏好。

### 阶段 C：分开测量 decoder 与生成分布的影响

固定输入与已有 latent，比较下表；它是阶段 B 后的诊断分支，不阻塞评测工具交付。

| latent 来源 | 原 HoLa decoder | 冻结 shared curve + UV decoder |
|---|---|---|
| GT posterior mean | roundtrip参照 | roundtrip参照 |
| 原 SVR 生成 latent | 基线 | 待测 |
| DPO 生成 latent | 基线 | 待测 |

使用同一受支持清单和固定后处理预算；3,495与3,505分母差异显式披露，不能静默删掉10件。

旧链含 latent 去重和解码后几何去重，新 decoder 不提供相同的隐式流程。先规定无 GT 的 slot保留规则。固定集合诊断需要两 decoder 都重跑相同集合，不能直接沿用旧正式数值；部署端到端替换另列，记录其去重变化。保留原始30槽和所有映射。

交付：组合收益、失败交集、几何参照。GT roundtrip不是数学上限，几何CD不能相减作为严格因果归因；decoder收益与DPO收益不假设可相加。

### 阶段 D：利用现有候选改善 DPO 标签

1. 阶段 A/B 完成后，把已验证指标应用到 train 已保存的8候选；validation用于规则设计，候选不进入训练。
2. **先保持每图最多一对**，形成新版配对 manifest。加入观测保护；对合法且观测上不可区分、仅隐藏部分不同的候选允许弃权。完整GT指标仍保存，不因弃权删除普通GT去噪训练。
3. 导出旧/新 pair 的保留、翻转、替换、弃权及无pair原因，检查不同几何复杂度/细节类别覆盖。可测性未知不能当负样本，也不为保持pair数量放宽规则。
4. 多pair与新policy候选作为独立后续增量：前者先按CAD均匀再按合格pair抽样，控制比较预算；后者单独记录生成policy、decoder和评价协议。不能把三项同时变动后声称收益来自标签。
5. 若最终采用新 decoder，偏好依据需要由该固定decoder重新评价，不能将旧decoder下的invalid标签直接沿用。

交付：新版候选评分、pair manifest、标签审计。不是先替换DeepCAD或盲目扩增图片。

### 阶段 E：冻结 decoder 的几何辅助训练与独立消融

先设计训练接口，再冻结运行配置：

```text
GT mean → 复制/排列并保存slot来源 → z_t [B,30,32]
图片 + z_t + t → diffusion → clean估计 z_hat [B,30,32]
→ 按明确规则还原每面输入 → 冻结decoder（保留对输入梯度）
→ 全局XYZ: surface [F,16,16,3] / curve [E,16,3]
→ 几何辅助损失 → 反传到diffusion
```

- 默认研究入口是在GT去噪分支计算辅助项，DPO分支保持原语义；不是对离线固定winner/loser算一个无梯度几何分数。
- 监督对象分开研究：真实GT raw几何，或 `stopgrad(D(z_GT))`。前者允许部分补偿decoder偏差，后者衡量对可重建目标的贴近；不混为同一个实验。
- 比较采用同一raw表示、物体坐标XYZ；不能把未裁剪网格当最终可见表面。训练GT拓扑/对应可以监督边，但不进入推理接口。
- 保存padding来源并明确复制slot如何还原，不能把30槽都当真实面。保留decoder全局attention语义；曲线硬筛选不能给漏边直接传梯度，需Tensor几何/edge logits及明确监督接口。
- 冻结decoder参数并使用eval，预测路径不包`no_grad()`，不转NumPy。只随机时间步估计clean latent，无需每步unroll全部采样；时间权重/噪声范围在正式运行前冻结。
- 总目标候选为 `L_ddpm + lambda_dpo * L_dpo + lambda_geo * w(t) * L_geo`。本计划不预设权重最优，不把几何辅助项自动称为不确定性保持方法。

公平消融先从同一个DPO step5000初始化，固定旧reference、原decoder、数据、seed、GT曝光次数和训练预算：

| 分支 | 目的 |
|---|---|
| 原step5000，不更新 | 现有交付参照 |
| 仅继续GT DDPM | 排除额外训练本身的影响 |
| 继续GT DDPM + 原DPO标签 | 偏好续训控制 |
| GT DDPM + 新DPO标签 | 单独检验标签改进 |
| GT DDPM + 原DPO标签 + 几何项 | 单独检验直接几何监督 |
| 合并有效改动 | 单项证据充分后验证互补性 |

几何目标的两种版本分开记录；多pair和policy候选更新也另做比较。初次消融不同时换decoder/主干。新增几何项会增加算力成本，报告等数据/步数比较及实际GPU小时，必要时另做等计算预算比较，不把两者称为同一公平口径。

## 6. Metrics

| 维度 | 指标/定义 | 信息来源与解释边界 |
|---|---|---|
| 产出与合法性 | requested、generated、STEP、native solid、invalid/unknown、超时比例 | 所有失败留在预定分母；solid独立重读检查 |
| 完整忠实度 | raw/post面边CD²、primitive F1、数量误差；保存两方向CD | 配对GT；固定归一化/采样；不等同观测一致性 |
| 输入一致性 | silhouette IoU、轮廓边界距离 | 输入灰模mask及固定相机；实际无GT选样可用，但不足以证明3D正确 |
| 可见几何 | 可见表面CD²、深度MAE、共同前景覆盖率 | 预测与GT各自渲染；依赖GT深度，不是部署时可用的图像分数 |
| 可见细节（新增） | 可见几何边界precision/recall/F1随像素容差的曲线；小尺度结构另列 | GT派生参考需标明；排除任意分面seam，区分孔洞轮廓与内部槽线；不把所有CAD边视为图片证据 |
| 合格候选比例（新增） | 每图 `q_i(tau)=sum(valid AND observation_pass(tau))/K`；再CAD等权平均 | 分开给输入mask门槛与GT辅助门槛；不可测计入未确认合格，同时单列unknown；报告固定阈值网格而非只挑最好点 |
| 同图变化（新增） | 合法且观测合格候选的整体/可见/自遮挡表面成对距离、近重复比例 | 固定裁剪后表面采样与相机；每图先汇总；不是越大越好，不称为概率校准 |
| 成本 | 每候选采样、解码、后处理、评测耗时与训练GPU小时 | K次预算与K=1分列 |

细节定义在阶段A中通过已知孔/槽、coplanar分面、遮挡与分辨率反例后冻结。可见几何边界主要依据深度/法线/裁剪边界及遮挡一致性；若与输入中的可识别线条不吻合，列为“GT派生可见几何代理”，不能伪称直接图像观测。低于输入分辨率的细节单列，提升渲染分辨率不代表输入有了更多信息。

同图表面分区使用同一相机下**各候选自身**的裁剪后几何和z-buffer；自遮挡部分与出视野/不可投影部分分开，后者不能当作有益隐藏多样性。冻结采样密度、可见判定容差与近重复容差，不用GT配准、ICP或最优旋转。分面不同而几何相同不应获得多样性奖励。

每图不足2个合格候选时，差异指标为N/A；同时报告0/1/≥2个合格候选的图片数，防止只剩容易图片导致均值虚高。两模型共同可计算的配对集合与各自覆盖率并列。可选GT best-of-K仅作oracle覆盖指标，任何实际候选选择都不能读取GT。

单一GT不能列举所有合理补全；候选差异和GT覆盖也不能自动认证校准。若后续研究概率校准，需要另定义可验证几何事件、概率估计和跨对象校准协议，本阶段不预设这项结论。

## 7. Decision Rule

- 阶段A的验收是指标能区分预设几何反例，且数值/缺失状态/信息来源可解释；不是某个模型获得更高分。
- 新方法至少要改善单次合法率、观测一致性或细节保真中的明确目标，并在其余关键维度给出退步界与不确定区间；退步容许范围在训练前冻结，均值变好但区间宽时保留为未决。
- 多样性降低若伴随错误候选减少，可能有益；隐藏差异增大若合法/观测合格率下降，不算成功。需要联合读取质量、差异与样本覆盖。
- 新标签必须能解释纠正了哪些错误偏好；直接几何项必须改善最终采样后指标，不能只凭辅助loss下降或raw CD改善宣布成功。
- 先比较固定步数终点；若按validation选checkpoint，所有分支采用相同预先声明的规则/次数。test不用于选择版本、容差或训练目标。
- 最终组合的价值由同信息、同预算下游指标决定；未来与通用CAD agent比较时沿用同样输入/重试/修复预算，不预设专用模型更优。

## 8. Edge Cases

缺失文件、NaN/Inf、空几何、无边、无前景交集、不可三角化、超时、崩溃分别记录，不填零、不生成原点几何。无参考内部边界时recall为N/A，仍统计预测的额外边界；双方边界皆空不计作一个高分细节样本。

合法性已确认而后续几何不可测时保留合法标签；可渲染invalid可计算观测指标但不能进入“合法且合格”子集。清单重复、source hash不符、相机/坐标不适配报错；不能静默切换run或跳过对象。未知终态不作DPO loser。

decoder roundtrip里历史不支持的10件列明原因并保留原总分母；原/DPO与共享decoder比较采用同一个明确集合。所有原始结果、旧pair和旧协议保留。

## 9. Validation / Sanity Checks

- 已知相同形状/面排列/额外coplanar分面不应显著增加几何多样性；平移、缺孔、可见槽改变应被相应指标发现。
- 只改真正自遮挡部分：观测指标应稳定，遮挡部分距离变化；新几何遮挡可见区域时必须影响观测指标。
- 检查GT自身重渲染、像素容差/网格精度、空边界与缺失候选；手工小表验证每图权重、固定分母和bootstrap聚类。
- 几何训练：真实小批量核对shape/loss/有限梯度；decoder权重无梯度更新而latent梯度非零；padding对应正确，含不同面数和空边情况。
- `z_hat=z_GT`时，对同一确定性decoder输出的几何目标应近零；相对真实GT的残差可非零。不能把两种目标的数值混为一个误差。
- 小规模验证只用于实现验收；研究结论来自冻结清单的最终采样、后处理和完整报告。

## 10. Implementation Constraints

复用 `eval/metrics/observation.py`、`conditional_diversity.py` 和审计工具；新增指标分开命名与版本，不改旧指标含义。训练沿用Hydra/Lightning与现有模块职责。所有数据/权重/输出路径配置化。
