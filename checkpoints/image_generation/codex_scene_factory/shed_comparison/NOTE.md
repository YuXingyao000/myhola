# The Shed 工作台与当前生成模板对照

2026-10-15。用户明确零件最长边约 **15–20 cm**。本次完成原工程下载、只读参数审计、布局图和四张本机诊断渲染；没有修改生产代码、当前模板、源 CAD 或 The Shed 原工程。

## 结论与证据强度

1. **尺度错误有直接依据。** 当前模板把最长边约1.8的归一化CAD解释成45 cm；用户要的是15–20 cm。环境道具本体大致是正常尺寸，因此CAD相对工具大了2.25–3倍。
2. **环境素材已经有重合，差距不能归结为素材分辨率。** 两个工程的电钻和油壶使用相同资产，8张对应1K贴图SHA逐一相同，主要材质节点及参数一致。区别更值得从大表面、布局、比例与光影研究。
3. **The Shed 的密度来自有使用关系的组合和高度层次。** 打开的工具箱、箱内工具、台钳、后缘容器与前方木刨相互接近、部分叠放。当前主要是大台面中央空区和外围少量独立道具。
4. **换入人工环境不自动修好目标。** 同一个杯形CAD、同一个材质放入The Shed后，圆柱分段高光仍明显，且原场景在该位置使金属很暗。现有STL导入实际是0个smooth polygon、存在custom normals。曲面着色与拍摄照明需要独立处理。
5. **可借鉴人工布景方法，但不能直接把艺术展示场景当作训练摄影协议。** 参考工程包含景深、遮光板、受控体积发光与尘埃。近景中孔槽可辨性仍要独立满足。

## 材质与光照具体差异

| 维度 | The Shed实际工程 | 对当前问题的含义 |
|---|---|---|
| 同源电钻／油壶 | 与当前工程8张1K贴图SHA全部一致，主要节点／Mapping一致 | 不支持“继续提高这两个道具贴图分辨率”作为优先措施 |
| 工作台 | 专用UV，4K颜色／金属度／粗糙度／法线图，Normal=1 | 纹理已按木板、金属部件、边缘等位置包含变化，不是给整个平面加一种噪声 |
| 台钳等工具 | 多为1K四图，包含局部掉漆、露底、污迹 | 丰富度来自空间一致的表面状态，不要求每件资产4K／8K |
| 当前钢台面 | ambientCG三图，Normal=0.22；粗糙度映射0.40–0.64，局部擦拭额外变化最多0.055 | 已有程序调整；其视觉幅度和分布是否过弱应通过后续单项比较判断，不能跨不同贴图直接按normal数值比较好坏 |
| 参考光照 | goegap HDRI、Sun、3个Area；窗口／结构遮挡、额外遮光物体 | 局部亮暗和反射形状来自光与几何共同作用，不是增加灯数量即可 |
| 当前光照 | 固定World颜色、侧窗Area和顶部Area，画外暗柜体提供反射 | 已考虑反射，但需要结合正确的零件尺度和拍摄位置重新检查 |
| 气氛 | 受控体积发光、透明＋发光尘埃、部分按光路选择的屋顶材质 | 艺术家也使用视觉技巧；这些不是必须照搬的PBR条件 |

原作者相机为20mm、16:9、f/1.2景深、Filmic，保存1500 samples；我们的诊断是降采样预览，不宣称像素复现官网图。没有发现合成器中的隐藏辉光／调色流程，活动连接只是Render Layers到输出。

## 同一个CAD放入人工场景后的结果

模型`00843446`最长边缩放到17.5 cm，底部贴合主台面`z=0.839586 m`，中心XY为`(0.50,-0.735)`。STL不改三角网格，仍按生产方式导入；沿用当前`build_material.py`。相机与CAD共同做等比／刚体变换，保持物体相对相机姿态和45° FOV，512²、256 samples、seed8。采用与当前模板一致的AgX Medium High Contrast、曝光0。

![17.5cm CAD在The Shed中的原曝光结果](/mnt/d/data/cad_scene_references/the_shed/comparison/cad_17p5cm.png)

为了看清暗处，另渲染仅曝光增加2EV的诊断图，没有改变灯、材质或法线：

![仅增加2EV的诊断图](/mnt/d/data/cad_scene_references/the_shed/comparison/cad_17p5cm_exposure_plus2.png)

可以直接观察到：工具与零件的比例更符合“小零件放在工作台上”；同一灰银色金属因木台和暗室反射呈暖色、暗色；侧壁分段高光仍然存在。材质参数没有变成棕色，不能仅凭成像颜色判断材质设置错误。增加曝光改善可见性，但没有消除分段。

当前CAD导入后实际2312个三角形、0个smooth polygon，存在custom normals。STL面法线不等价于B-Rep曲面连续法线。这轮没有实施法线修复或单变量法线实验，不能宣称全部不真实感都由法线导致；但曲面着色问题已经有代码、数据与跨环境图像依据。

这组比较同时改变环境和物理尺度，不能据此量化某一种灯光、贴图或布局的独立收益。+2EV这一对只改曝光。原艺术场景的暗部也提醒我们：场景可信与CAD孔槽充分可辨是两个要求。

## 固定相机下的需求收敛

归一化长边1.8对应15–20 cm时，1单位应解释为8.33–11.11 cm；固定相机距CAD原点约29–38 cm，中心深度的画面宽约24–32 cm。CAD画面占比保持不变，摄影任务变成**小范围工作台近景**。

因此改进不应是把The Shed整间房的物件塞进512图，而应优先考虑：

1. 在协议中明确15–20 cm尺度，区分道具自身尺寸与摆放位置；不能只改单位文字，也不能直接把整套位置放大2.25–3倍。
2. 保留CAD与相机约定，处理曲面连续着色和真实锐边。暂不以全局平滑、加倒角、细分或随机噪声掩盖问题。
3. 围绕近景安排少量相互关联且足够靠近的物品组：允许画边裁切、后侧堆叠、打开的容器、局部活动痕迹。大表面采用与使用状态相符的UV资产／局部材质层。
4. 单独校准拍摄位置的主光、补光、反射环境和曝光，使孔槽在可信照明下可辨；不要直接复制The Shed的暗部风格或功率数值。

上述是下一轮建议，本次未修改提示词、材质生成器或渲染管线。
