# 布景工作流接入（2026-10-15）

## Task

将已讨论的中文布景指南、素材获取、固定预览和验收证据接入扁平脚本工程。仍由一次 Codex 任务制作模板，批量渲染不调用模型。

## Assumptions

- 已有两个 builder 接口、固定相机、支撑对齐和 AABB 检查保持有效。
- 用户接受按原始 B-Rep 面数选择 12 个训练零件；不再增加形状类别配额。
- 素材来源包含 Poly Haven、ambientCG、CGBookcase、Sketchfab 和本地目录；只有实际可用的接口才称为已接入，认证不由模型索取或写入提示词。
- 本轮不启动新 Codex 生成，不修改 workshop_002 及源 CAD。

## Inputs

现有模板脚本、用户需求、中文指南；显式的 Blender／STL／素材目录；已有训练 split 和原始 CAD；可选素材服务授权。

## Outputs

独立指南与验收说明、实际可调用的工具入口、固定样本清单、每次预览的新输出目录、逐样本记录及汇总、调用输入快照。

## Processing Protocol

1. 沿用首轮已看过的 12 个入镜合格训练零件，按原始 STEP 面数重排并冻结；quick 使用其中低、中、高各一个，不声称该组覆盖全库面数分布。
2. call_llm 显式载入本项目指南和工具配置，保留新会话、ChatGPT 登录及个人上下文隔离。
3. 素材工具检索、缓存和复制文件，记录来源、许可及真实 SHA-256；不依赖临时下载 URL 作为永久资源。
4. 预览工具重新构建当前源码：quick 为 3 件、64 samples；review 为 12 件、256 samples，加三个支撑高度的空场景。
5. 预览保留全体计划样本及失败；机器报告与 agent 的目测结论分开。人工审阅在任务退出后进行。

## Metrics

本轮报告构建状态、计划／成功／失败样本数、图像可读性与尺寸、已有几何检查、源码和素材摘要。视觉真实性仅记录具体图片中的观察，不发明自动真实感分数。

## Decision Rule

所有计划检查成功才可报告相应技术检查通过；视觉状态初始为 pending。quick 不等于 review；采样检查不等于全库通过。未实现或未执行的迁移等检查明确标记，不宣称通过。

## Edge Cases

缺少认证或供应商接口时明确返回不可用，不伪造素材；缺失文件、错误摘要和构建失败写入报告；单件失败保留在固定分母中。旧图片不能替代修改后源码的检查。

## Validation / Sanity Checks

不消耗 Codex 额度：用替身进程核对调用输入；实际 Blender 对 workshop_002 执行固定预览；使用故意失败的样本验证报告。素材用小文件／本地夹具核对复制、缓存、摘要和清单，联网检索单独标记。

## Implementation Constraints

保持扁平模块、清晰主流程、少量依赖；不恢复旧 src/examples/tests，不增加复杂 agent 框架，不修改其他研究主题或现有数据。

## Deliverables

中文独立 Markdown；可审阅的调用与工具改动；README 使用方式；本文件追加实现与实际验证状态。代码和数据输出分开存放。

实施与验证已完成，见同目录 `WORKFLOW_NOTE.md`、`WORKFLOW_VALIDATION.json`。
当前未实现 CGBookcase 在线检索、Sketchfab 登录与自动续期、自动外层模型修复循环；
单个模板的迁移测试仍需单独执行，预览报告明确记录该项未运行。
