# 局部摄影修图：DeepLPF 与受限局部光色投影

## Task
继全局LUT未解决真实感后，实际评估具有空间变化能力的轻量局部修图。使用作者官方DeepLPF预训练，
另将其输出投影为作用于原图的平滑局部增益，比较摄影明暗改变与结构保护的取舍；不继续扫LUT混合参数。

## Assumptions
输入为已做显示变换的sRGB512 PNG，不是RAW/HDR。官方当前默认权重是2026维护版在重建FiveK划分上训练的模型，
不冒称2020原论文权重。DeepLPF含U-Net像素分支，不具有严格几何保证；受限投影不移动像素，但仍可能压缩可见细节。

## Inputs
沿用`phone_camera/samples.json`固定六张、顺序与CAD来源；均为training开发输入。模型来源固定
`sjmoran/deeplpf-image-enhancement` commit `4faeef6597f299d38acc597df9cfe970f8d90ca2`，
默认`pretrained_models/adobe_dpe/deeplpf_psnr_24.180_ssim_0.917_model.pt`。

## Outputs
每件原模型结果`deeplpf.png`、受限局部光色结果`local_gain.png`、增益场可视化、与原图三栏对照；共12张增强图。
冻结输入/源码/模型摘要、运行时间、裁剪与目标内颜色变化等描述统计。所有原图保留。

## Processing Protocol
1. 下载固定官方源码与约6.9MB权重到独立模型目录，保留LICENSE，检查网络结构与strict权重加载。
2. 使用CPU4线程运行官方网络，输入sRGB[0,1]，不重训、不逐图改参数。
3. 作为独立衍生对照，将原图与官方结果转到线性RGB；高斯平滑各通道（sigma=24px），
   计算`(平滑输出+0.01)/(平滑输入+0.01)`，限制增益[0.5,2]；原始线性RGB乘该平滑场后转回sRGB。
   此操作只提取局部光色趋势，不转移原网络的高频像素结构，参数所有六图固定。
4. 保存完整官方输出与投影输出，不自动选优、不回贴CAD、不将无位移误称全部几何可辨。

## Metrics
6件×2方法覆盖率；推理/投影时间；输出尺寸/有限性/摘要；局部增益空间方差与范围；目标内RGB变化、
黑白截断及边缘信息变化描述。实际看全部六组三栏图，记录暗部、金属、墙/桌面的摄影感与伪影。

## Decision Rule
空间变化能力必须由实现与非恒定增益证据支持；真实感由实际看图单列，不因颜色差大自动判好。
若仅变化影调但未改善CG感，则明确说明未解决目标，不扩批量、不增加参数搜索。

## Edge Cases
固定输入缺失/尺寸错误/NaN/Inf直接报错并留下运行目录；失败计入12张分母。原图极暗区域由分母稳定项和增益限制处理，
不重新生成图像。新目录不覆盖旧产物。

## Validation / Sanity Checks
官方权重strict加载与参数计数；官方模型原始调用作为主结果，不静默改结构。
官方model.py顶层导入仅用于训练的losses，进而要求当前环境没有的Matplotlib；适配时只跳过这一条未使用导入，
保留其余全部定义与权重，不安装/改动环境。记录该适配以及官方源码hash。
投影检查恒等输入输出应近似恒等、可变光照生成空间增益但不改变采样坐标；读取全部输出摘要/尺寸并逐图检查。

## Implementation Constraints
只使用CPU、已有Torch/NumPy/Pillow/SciPy，不修改训练环境及共享step4/model.py。
本目录放原型代码/配置/记录，下载模型源码为独立目录。保持公开来源、许可与版本可追溯。

## Deliverables
局部修图选型依据、可独立复现的CPU原型、12张结果与六组对照、完整验证与视觉记录；
明确它没有复现iPhone ISP，也不保证能修复渲染光照/材质的根本不足。
