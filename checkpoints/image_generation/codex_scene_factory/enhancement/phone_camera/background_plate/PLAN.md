# 背景底图增强与零件光影合成

## Task
将背景照片化与CAD/接触光影分开，检验是否能解决生成器在零件旁新增结构、
错误补影的问题。另用边缘条件检验现有深度增强造成的背景设备变形。

## Assumptions
前两轮已验证小模型调色不能修复材质；扩大保护圈引入纹理岛；只描述背景材质
减少新增物但没有保证正确接触。本轮是机制改动，不继续扫描strength或seed。
成对渲染来自同场景、同机位、同光照。PNG带AgX，逆sRGB后仅为显示线性值，
不是场景辐射；差分合成是显示域近似，不能宣称物理精确重光照。

## Inputs
沿用`../samples.json`六件training开发样本。成对渲染沿用各自原render seed
（前五8–12，00320493为17）；增强种子仍8–13。源相机、姿态、尺寸和材质不改。
仅使用GPU7；局部修图CPU。原100件与此前候选不覆盖。

## Outputs
每件with_part/empty的RGB、二值mask、深度、scene-linear EXR；冻结源码与输入。
增强空背景E，再保存additive和relative_darkening两种合成，各含raw和CAD原像素保护版。
源图、空背景、增强背景、合成图并排，失败保留在六件分母。

## Processing Protocol
1. 重建六件源场景与相机，渲染有CAD/完全移除CAD的配对图；同seed、256 samples。
2. 用无CAD背景深度构造近白远黑控制。Krea+现有Depth、512、40步时间表、
   strength=.65、guidance=4.5、control=.5、end=1；全帧可编辑，使用实际背景材质提示词。
3. 第二候选改用Union Pro 2 Canny控制（官方512训练、公开固定权重）：
   cv2.Canny阈值100/200，输入空背景RGB转灰；control=.7、end=.8，其他同上。
   这是更换结构约束模型的工程候选，不宣称只改变单个条件类型。
4. 使用配对图差分转移CAD引起的接触影/反射变化；CAD mask+2px逐字节回贴。
   完整公式、显示域边界、数值验证见独立COMPOSITE_SPEC。两种公式都保留，不挑样本。
5. 六件全部实际看图。若生成空背景引入占位物或改变支撑平面，明确失败；
   原渲染光影不能自动与新几何/新光源兼容。

## Metrics
输入/相机/模型来源和摘要；with_part与旧RGB差别；empty mask必须全零；
E=B时合成应复原I；CAD保护差为0；输出截断/范围/边缘信号；覆盖、耗时与显存。
视觉判断接触、阴影、反射、孔槽、背景设备形状及照片质感。指标不代替看图。

## Decision Rule
移除错误底座但保留悬浮接触影不算通过；背景照片化但设备严重变形也不通过。
不把合成恒等测试或原像素保护当作整张图几何保证。不扩大100件或改生产默认。

## Edge Cases
缺文件/不合法输入直接失败；逐件唯一异常边界保留剩余任务；空背景mask全零合法。
除法暗像素处理固定，非有限输出失败；不静默替换相机、场景或CAD。

## Validation / Sanity Checks
成对渲染源契约检查；RGB/EXR坐标与颜色空间明确；两种公式恒等及暗底合成CPU测试。
分别保存渲染seed与增强seed。检查空背景生成是否在未来CAD位置新增物件。

## Implementation Constraints
独立研究目录，不改变Step2/3生产实现；复用模型加载，新增可选通用control_image。
提示词/参数独立文件，代码保持简单函数；无逐图Agent调用、训练或新增付费服务。

## Deliverables
可复现成对渲染/增强/合成脚本、六件全量对照、实际审阅与限制记录。
许可/版本/大权重摘要保存在模型目录；组合Krea与新ControlNet不冒称官方验证。
