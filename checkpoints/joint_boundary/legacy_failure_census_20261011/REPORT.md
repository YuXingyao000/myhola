# 原版 VAE 全部失败的溯源结果

先把它想成三个步骤：**画出面和边 → 用边裁出每个面的轮廓 → 把面拼成一个没有破口的实体。** 我们查到的问题，可以用下面六句话说明。

1. **边没能围成一圈（73 件）。** 至少有一个面的边界，经过修复仍没有形成可用的闭环。就像沿着轮廓剪纸，轮廓还留着口子，程序没法据此剪出这个面。
2. **圈闭合了，面仍然裁不出来（216 件）。** 首尾接上只是第一步。比如线交叉了，或者线没有贴在这个曲面上，闭合了也未必能裁出面。我们已确认这批有闭环仍失败，但还没把每件具体是哪一种情况分清。
3. **难处理的一圈边，被程序丢掉了（143 件）。** 程序舍弃没闭合的环，再用剩下的边界做面。面虽然做出来了，却没有保留全部输入边界。如果丢的是孔的边界，孔就可能被填平；目前还不能说这些件都丢了孔。
4. **边和它所属的面没有贴合（333 件）。** 单看面和线可能都挺像，但放在一起，线没有落在它应该属于的曲面上。就像两个零件尺寸各差一点，摆到一起就对不上。这是最终测到的偏差，还不能一概归责于模型或后处理。
5. **两条边挨得很近，在 CAD 里却仍各算一条（159 件）。** 这可能解释你看到的“同一个位置有好几条线”：它们靠近，却没有共享同一条 CAD 边。不过靠得近也可能是正常薄壁，不能看见两条就直接合并。
6. **一开始就把面连错了（多连 90 件、漏连 27 件）。** 本来不相连的面被预测成相连，或者本来该相连的面没连上。后处理拿到的拼装关系一开始就有错。但多数失败零件的面连接关系其实是对的，问题不止在这里。

同一零件可能有好几个问题，数量不能直接相加。333 和 159 件采用归一化坐标下的距离标准 0.01，不是毫米，也不是说这个数字能直接判定零件必然失败。

**现在更值得追的是：这些面和边能不能互相对上，围出正确的边界，最后拼到一起。** 仅仅知道哪两个面相邻，或者把线头接上，都还不够。另外，后处理优化确实能帮忙：它救回了 998 件，也把原本成功的 8 件弄失败了。需要查清它何时会改坏形状，不能简单停用。

下面保留具体统计和计算方式，方便需要时核对。

## 1. 裁剪阶段直接观察到什么

以下是主构造路径最终仍失败的面，或最终成功返回面时实际舍弃的 wire。没有把低容差失败、后来修好的尝试算成持续阻断。对象标签重叠，分母均为 369。

| 持续机制 | 对象数 | 面数 | 解释 |
|---|---:|---:|---|
| 接纳过闭合 wire，但最终仍无法裁剪该面 | 216（58.5%） | 339 | 仅让端点相遇并不充分 |
| 上一组中，存在所有候选 wire 都闭合并接纳却仍失败的尝试 | 207（56.1%） | 见逐件明细 | 排除了“那次只是另一个候选 wire 没闭合”这一解释 |
| 有候选 wire，但所有容差下都没有接纳闭合 wire | 73（19.8%） | 218 | 可以明确定位到闭合/修复门槛 |
| 最终返回的裁剪面舍弃了开放 wire | 143（38.8%） | 277 | 面能返回并不保证所有输入边界被保留 |
| 始终组装不出任何 wire | 0 | 0 | 本批失败并非全部卡在最初组装调用 |

主路径共有 254 件丢失至少一个可裁剪面，合计 557 个失败面。另有 4947 个面返回，其中 277 个在成功尝试中丢弃开放 wire。上表两种明确开放环问题的对象并集是 **170/369（46.1%）**，交集 46 件。不能仅凭这些记录把丢弃的 wire 叫作内环或孔。

![持续裁剪机制](charts/persistent_trim.png)

557 个失败面中，214 个面涉及 raw 错误/缺失 pair 的端点；**343 个面的局部无向 adjacency 与 GT 一致，仍然裁剪失败**。这只是无向 pair 正确，不包含方向、UV 参数域、多重边或几何贴合正确。

具体 UV 自交、环嵌套、方向/参数域错配目前仍未逐件唯一归因。记录了闭合候选、丢弃分支和上下文错误，但不能将一个 BRepCheck 名字改写为已证明的上游根因。

## 2. 上游到底有没有多边、漏边或去重错误

本次推理在 `tools/vae_compare_inference.py:219` 明确设置 `v_deduplicated=False`，面身份/数量来自编码输入。**面 latent 去重没有执行，面数偏差为 0；不能把此批归因于 diffusion 的面去重失败。** 同时测量了解码面网格异常接近，见阈值表；它不是已裁剪 CAD 面重叠的精确判据。

| 阶段/现象 | 对象数 / 369 | 定位 |
|---|---:|---|
| raw 额外无向 face pair | 90 | 后处理前已经出现额外连接 |
| raw 缺失无向 face pair | 27 | 后处理前已经缺边 |
| raw 任一 pair 错误 | 101 | 上两项重叠 16 件 |
| raw 无向 pair 集完全正确 | 268 | 正确 adjacency 并不足以重建 solid |
| raw 同方向 pair 重复 | 0 | 不能把双向半边当这类重复 |
| 半边选择移除了原本存在的正确 GT pair | 3 | `00295085`、`00578255`、`00772578` |

原始 24965 条曲线记录 = 12423 对正常 reciprocal 半边 × 2 + 119 条单向记录。后处理按无向 pair 选择一条曲线，再供两侧面使用。这不是对所有空间近邻曲线做全局去重，也无法纠正不同错误 pair 各自留下的一条边。

成功组的 raw 任一 pair 错误仅 **20/2048（1.0%）**，失败组为 **101/369（27.4%）**。按 1–9、10–19、20–30 面分层、共同分布加权后约为 1.04% 对 23.56%。这是明显关联；未控制其他形状复杂度，不能解释成独立因果效应。

## 3. 视觉上的“同一条边附近好几条边”有不同来源

正常 reciprocal 半边、不同 pair 的异常近曲线、最终 STEP 中尚未共享拓扑的近重合自由边分别计数，不能合并为一种“重复预测”。

以下阈值为归一化 XYZ **长度** 0.01，不是平方 Chamfer 距离，也不是毫米。新近重合要求预测接近且同一对 GT 曲线不接近；没有 GT 对应的额外 pair 保留未知，不硬判重复。

| 观察 | 确认正例 / 369 | 未知 / 369 |
|---|---:|---:|
| raw 不同 pair 出现 GT 没有的曲线接近 | 21 | 40 |
| 半边选择后出现上述接近 | 11 | 39 |
| 优化后出现上述接近 | 42 | 31 |
| 原 STEP 不同面上的不同拓扑自由边空间接近 | 159 | 0 |
| raw 面网格接近、但对应 GT 面网格不接近 | 2 | 0 |
| 优化后出现上述面网格接近 | 11 | 0 |

**159 件里有 89 件 raw 无向 pair 完全正确。** 所以截图中的多条边不一定是 intersection 多预测了连接，也可能是裁剪/修复后两侧边没有合并成同一条拓扑边。接近本身不能证明应当焊合；正常薄壁等情形仍需具体结构判断。

原 STEP 303/369 件存在自由边；空间接近自由边筛查在 0.002 / 0.006 / 0.01 / 0.08 下分别命中 39 / 129 / 159 / 211 件。页面提供阈值敏感性，避免把 0.01 当成唯一物理标准。

## 4. 精度问题：自身拟合准，与彼此能接合是两回事

在最终拟合几何上测量输入点到拟合结果、有效曲线到所属两侧曲面的距离。面/边自身拟合各用 16 个输入采样点；边面测量使用周期替换后实际曲线的 9 个原生参数采样点，投影到两侧有限拟合曲面。两组并非完全相同的采样与曲线对象。使用有限采样最大残差，只是筛查，不是连续曲线的严格误差界，也没有排除拟合/周期替换造成的问题。

| 拟合后最大采样残差 > 0.01 | 对象数 / 369 |
|---|---:|
| 面输入点 → 该面拟合曲面 | 2 |
| 边输入点 → 该边拟合曲线 | 0 |
| 周期替换后实际曲线 → 所属两侧拟合曲面 | 333 |

也就是说，拟合器通常把各自的输入点拟合得相当近，**各自拟合好却不保证边落在两个面上**。这比“提高单独 surface/curve fitter 精度”更有针对性。216 件闭合候选仍裁剪失败的对象中，119 件在同一个失败面上测到所属边面残差 > 0.01，说明两种现象有具体面级交集。

333/369 是失败组内发生率，未对 2048 个成功对象新跑同样残差，不能宣称该阈值具有已知的失败预测能力。拟合误差小也不排除局部未采样偏差、周期接缝和 UV 裁剪问题。

## 5. 几何优化在改善什么、牺牲什么

所有 369 件的总优化 loss 首末记录下降，但其中 361 件面坐标 GT MAE 上升、354 件 matched curve-to-GT 距离上升。边指标只比较有 GT pair 对应的边，额外 FP 不混入；这里的 distance 不是边长误差。

端点残差 > 0.01 的确认正例从选择后的 284 件降至优化后的 97 件，但未知同时由 9 增至 42 件：无 GT 对应的额外边存在无法确定闭合语义的情形，不能把“非正例”全部当改善。端点最近邻接近也不等于可构造合法环。

不能据此关闭优化。全体 2417 个对象的既有配对结果是：

| fit-only → optimized | 数量 |
|---|---:|
| 成功 → 成功 | 1050 |
| 失败 → 成功 | 998 |
| 失败 → 失败 | 361 |
| 成功 → 失败 | 8 |

对最后 8 件额外重放 fit-only，输入/选择后的数组完全相同，原/重放 STEP DATA 均一致。优化 loss、端点残差都改善，GT 面/边误差均恶化；4 件首先在主裁剪丢面，4 件所有面返回后在 sewing/solid 构造失败。97 个面的拟合 precision 全部不变，只有 `00677369` 的一条边改变拟合 precision，不能统称为“拟合器选错精度”。

`00326520` 在所有 8 个 sewing 容差下自由边都是 0，仍无 solid；`00730675` 有 3 个闭合候选 wire 全被接纳但出现 IntersectingWires；`00677369` 返回面时新增丢弃 wire。完整记录：[optimization_regressions.json](optimization_regressions.json)。

这是启用/关闭整体优化路径的对照，不能归因到单个 loss 项；路径变化还可能改变后续随机 shuffle 的消耗。日志最后一项发生在最后一次参数更新前；几何差值测量最终返回结果。

## 6. 末端阻断与后续研究优先级

互斥末端分支：裁剪面数量门槛阻断 59；进入 solid 构造但未返回 solid 301；内存 solid 返回、旧保存检查拒绝 8；旧检查通过但原生重读无效 1。合计 369，未知 0。**这是流程停在哪里，不是根因排行榜。**

根据上述溯源，我建议优先处理：

1. **共享边、两侧曲面与面内环的联合一致性。** 已有 adjacency 正确的多数失败，以及闭合候选仍失败、边面残差的交集，都说明只增加 topology classification 不充分。后续架构需要让这些几何量互相约束；具体采用 UV boundary、共享顶点/环结构或其他方式仍待设计。
2. **显式保留所有需要的边界，并解释裁剪失败。** 不应以“端点近”“返回了面”为完整约束；143 件最终面丢弃开放 wire 是明确可追踪的缺口。
3. **额外/缺失 pair 及半边选择。** 101 件离散错误有清楚的上游证据，3 件选择删除正确 pair 值得单独看。但先把最终 STEP 近重合自由边和 raw 多预测区分开。
4. **优化目标与保真、有效性的权衡。** 保留已证实的修复收益，针对 8 件退化路径和普遍的 GT 几何漂移设计约束，而不是把更低后处理 loss 直接当研究成功。

这些证据尚不能区分 latent 不平滑、网络容量小或融合失效的贡献；那需要直接针对表示/模型的干预。当前已把讨论从全凭截图猜测推进到具体接口与几何约束，尚未声称每件有唯一已证实根因。

## 7. 可复核性

- upstream 与原 STEP 诊断均 369/369 完成。状态 ok 不代表每个 GT 依赖标签都可知；未知随各项指标保留。
- 拟合采样：5504 个曲面、12527 条曲线、25054 个边面 incidence 的记录完整；长明细留在本地 `cases.json` 与 `traces/`。
- 1845 个原 GT/raw/STEP 资产 SHA256 未改变；39 项相关测试通过。只新增诊断工具和记录，没有改模型或后处理决策。
