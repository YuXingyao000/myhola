# VAE失败案例交互查看器

交付：[打开单文件HTML](failure_viewer.html)。使用现代Chrome或Edge直接打开，无需服务器或网络。文件内含全部316件几何，约120MB，首次打开需等待加载；之后逐件解压，浏览器只缓存最近3件。HTML为本地生成产物，源码、固定统计和审计记录受版本管理。

本页覆盖no_edge_feature64在固定3495件validation中的全部316件OCC失败：307件裁剪失败、6件实体构造失败、3件STEP原生／边界检查失败。与source32配对，其中29件是32维合法而64维失败，287件两版均失败。未修改训练或后处理，也未重新评定正式合法率。

## 怎么看

1. 左侧搜索CAD ID，或按阶段、配对变化筛选。用“上一件／下一件”及键盘左右键逐件查看。
2. 默认显示最后恢复路径的拟合几何，选中第一张失败面和该面偏离最大的边。拖动旋转、滚轮缩放；选择“只看选中面和边”可排除遮挡。
3. 点击边—面明细中的一行，查看其mean/P95/max与逐点曲线；“放大最大间隙”聚焦边与所属曲面间的投影连线。
4. 切换原始预测、拟合后和GT；也可叠加GT边界。所有视图使用原归一化坐标，不重新对齐。GT仅供诊断，不参与修复。
5. 右侧逐面日志显示每档容差下的开放wire、丢环等记录；非trim失败则显示solid/STEP尝试。切换历史路径只切换日志，不把其他路径的几何冒充当前拟合结果。
6. 页面底部查看直方图或累计分布。原始预测包含合法3179件背景；拟合后仅对失败316件重放，成功组未测。

推荐先查看：`00024146`面6（修复时丢环）、`00003999`面4/16（开放边界）、`00208610`（包含无输入边的面）、`00356252`（各面裁剪已通过，实体构造失败）。

## 哪些是实际记录，哪些是测量

历史最后路径未保存裁剪前中间几何。本任务按原CPU优化／拟合配置重放`fit_score_v2_roundtrip_optimized`，捕获周期边替换后的拓扑边，随后运行原裁剪逻辑。**316/316的逐面完整日志、选边数和周期替换索引与历史严格一致。** 这是可核验的诊断重放，不是当时保存的快照。solid构造阶段跳过，页面继续引用原评估终态与历史solid日志。

重放共4954面、11290条选后拓扑边、22580组边—owner关系，测得1,445,120个解析投影点，无投影缺测。原始预测的半边编号与后处理拓扑边编号不同；查看器根据各自connectivity选择边，面索引一致。

所有距离均为**归一化XYZ中的L2长度**，不是毫米，也不是平方Chamfer。

| 测量 | 定义与边界 |
|---|---|
| 拟合边面距离 | 每条实际拓扑边64个等参数采样点，到其有界解析owner曲面的OCC最短距离；显示面网格不参与测量。采样最大值不是连续曲线最大误差上界。 |
| 原始边面距离 | 复用原评估：每边16点到16×16面网格三角片距离。GT同样存在离散网格近似。 |
| mean | 对象内各边—owner关系均值等权平均；跨对象按CAD等权。 |
| 对象P95 | 先算每组边—owner的点距P95，再取对象内最大值，不是合并全部点后的P95。 |
| 端点最近连接候选 | 同owner其它边最近端点与自身曲线首尾间距的较小值。仅为局部候选下界；可能选择退化自闭合，不证明正确的wire配对。 |
| 原不同边端点代理 | 对严格闭合曲线采用自身接缝，其余找另一边端点。近闭合整圈曲线可能被匹配到远处另一环，因此另保留自身首尾距离及可切换连线；122条原代理unknown继续保留。 |

原始端点诊断仍使用原协议中的GT闭合类型标记；它与拟合后无GT的候选代理不是同一指标。端点unknown记录数与无输入边的面数分别统计，不混合单位。距离汇总不以零填补缺失。显示坐标压缩至六位小数，数值指标保持测量精度。

## 已确认的结果

末路径共有767张未通过裁剪的面，按最后一次尝试的日志分类：

| 历史记录 | 面数 |
|---|---:|
| 开放wire被跳过，边界不完整 | 362 |
| face修复使wire数量减少 | 318 |
| trim拒绝，日志未细分原因 | 84 |
| 无输入边 | 3 |

316件失败对象拟合后的CAD等权边面平均距离为**0.00219104**；每CAD最大距离的中位数为**0.01858037**，P90为**0.05420516**。767张失败面中764张有边可测，面等权平均距离均值为0.00449486；同批对象内4187张通过trim的面为0.00147731。这些是当前失败全集内的描述统计，不是成功对象与失败对象的完整因果对照。

原流程已经逐次尝试0.002/0.006/0.01/0.015/0.02/0.025/0.05/0.08。边贴近面、端点接近都不等于wire拓扑和裁剪结果正确；本查看器不能证明越过某个单一距离阈值就会提升多少合法率，也没有依据这些validation对象调整任何规则。

详细数值见[summary.json](summary.json)、[逐对象指标](metrics.csv)；重放原协议和结果见[replay_summary.json](replay_summary.json)。新增的端点候选是页面打包阶段的诊断派生，原重放端点记录完整保留，不修改OCC或历史裁剪判断。
