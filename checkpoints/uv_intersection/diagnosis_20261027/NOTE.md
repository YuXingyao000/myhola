# UV 曲线退化与面改善：源码审计和只读诊断

日期：2026-10-27（北京时间）。依据最后30k权重的3495件原始评估；本次未改模型、loss、checkpoint或开启训练。

当前判断：64D容量不是首要嫌疑。相同维度的旧模型已有更好曲线结果；本轮同时改了几何表示、输出头、读取任务及监督，不能把退步归因于一个未验证的loss系数。面头结构保留也不意味着其输入、梯度和最终权重未变。

## 实际改变了什么

| 内容 | 旧64D no-edge-feature | 当前UV模型 |
|---|---|---|
| 几何共享 | 一次3D curve CNN/bbox输出，两侧反向复用 | 一组query输出双侧UV，分别在两张面上求值 |
| 全局曲线目标 | XYZ L1 | 双侧XYZ MSE |
| 相对曲线形状 | 每边归一化local L1，coarse及final | 删除 |
| 曲线位置/尺度 | bbox L1，coarse及final | 删除；不意味着必须恢复独立bbox头 |
| Encoder边辅助几何 | local/bbox各权重1 | 删除 |
| 特征匹配 | 权重已为0 | 删除；不是此次退步的新变量 |
| UV | 有有效GT UV L1及anchor | 无直接UV监督 |
| 面final输入 | F+refiner的ΔF | F |
| 训练 | 来源自身训练至30k | 从来源再全量训练30k |

代码：`models/vae/losses/intersection.py:125,186,246`、`decoders/intersection.py:384,416`、`uv_intersection.py:49,443`。旧incidence与UV anchor也能更新面，不应说本轮首次允许曲线loss回传面。

MSE和L1的标称权重同为1不表示同等输出梯度；新曲线梯度还经曲面Jacobian与sigmoid。删除按边尺度归一化会降低小边相对形状误差的权重。这是机制分析；尚无网络实际逐loss梯度范数/冲突测量，不能声称已证明面梯度压倒曲线。

## incidence 不是唯一问题

两侧预测a,b，共同正/反序GT为y；m=(a+b)/2，d=a-b。代码的曲线目标精确等于：

`0.5*MSE(a,y)+0.5*MSE(b,y)+0.1*MSE(a,b) = MSE(m,y)+0.35*mean(d²)`。

GT目标自身已经提供0.25的两侧差异惩罚，因此不是只靠0.1约束。增大incidence不能单独纠正共同错位、UV求逆难度、目标不在预测面上或局部精度监督缺失。旧硬共享几何变成新软共享几何，是架构取舍。

## 参数迁移不等于功能迁移

旧模型182,982,439参数，保留170,229,690，删除12,752,749，新加469,957；新模型170,699,647。
99.7247%是新模型中来自旧权重的比例，旧模型保留比例为93.0306%。被删部分包括成熟3D边头和refiner等关键几何路径。

进一步，旧`AttnIntersection`每个candidate的query和memory均长1（`decoders/intersection.py:56`）；新模块长16和512。单key的softmax数学上恒为1，旧任务没有提供选择不同局部位置的attention信号。V投影、残差、FFN仍能有用，不能说全部迁移无效，但不能认为已迁移“空间定位能力”。

CPU算子检查：PyTorch MHA，width32、4heads、dropout0、batch2，随机种子42。1-query/1-memory下Q/K梯度范数约2.57e-8/3.49e-8、V约0.456；16/512下分别0.00267/0.00298/0.00344。前者Q/K微小值属于浮点计算而非非平凡位置选择；这不是实际checkpoint梯度测量。公式参考[PyTorch 2.8](https://docs.pytorch.org/docs/2.8/generated/torch.nn.MultiheadAttention.html)。

协议和执行见[SPEC](SPEC.md)、[脚本](diagnose_surface.py)、[结果](surface_first32_v1/summary.json)。32/32件成功，401面、891 active边、890 GT边、890匹配边；第一批固定ID，不能外推代表全部validation。

保留预测UV，只把预测面替换为GT网格经过**同一固定B-Spline规则**重建的曲面；这是oracle诊断，既不是部署操作，也不是原生CAD GT连续面。

| 指标，890条匹配边等权 | 预测面 | GT网格重建面 |
|---|---:|---:|
| 曲线共同正/反序最小坐标MSE | 0.000666233 | 0.000654440（-1.77%） |
| 两侧对应点平均间距 | 0.0408355 | 0.0397195（-2.73%） |

这批样本说明只修正面节点预测，几乎救不回曲线。剩余问题集中在UV轨迹/对应及固定曲面表示的学习链路；尚未分离GT样条对GT边的可达性、UV输出头、训练目标或训练预算各自的因果。

## 连续曲面也存在独立数值风险

令H(u)=basis(u)·B⁻¹。实际cond(B)=19.0843，可解但在u≈0.027/0.973处有||H||₂≈6.40018。
独立同方差节点白噪声假设下，二维输出的单坐标噪声标准差增益可达40.9623；这不是实际误差倍率。

真实32件中，pred和GT分别用同一规则插值，再在相同参数处比较：

| 位置 | 三维RMS，全部点加权 |
|---|---:|
| 原16×16节点 | 0.00265361 |
| 65×65网格 | 0.00517567 |
| 离参数边界0到0.05的内部带 | 0.0108569 |

这说明节点间误差放大实际存在，但结合GT面替换只改善1.77%，不把它单独宣判为曲线退步主因。上述误差不是到真实CAD曲面的距离。
预测UV点中56.82%距参数边界小于0.01；没有这批新chart下的GT UV，不能断言这些点本应全在边界。
sigmoid在接近0/1时梯度变小，与局部Jacobian可能共同影响优化；现阶段为有机制依据的假设。

## 对后续设计的约束

保持64D作为当前容量基准；先把连续面数值稳定性、曲线的绝对/相对精度目标以及双侧如何构造共同边三项一起说清楚。不要默认只提高incidence、扩大latent或再叠一层refinement。
曲线监督可以继续施加在UV求值后的XYZ上，并不需要为恢复相对精度重新引入独立3D边预测头。
面改善当前只能归于整体训练变化：额外30k全量更新、删除refiner面改写、辅助监督与边面梯度重分配均同时发生，没有同预算控制组将其分离。
