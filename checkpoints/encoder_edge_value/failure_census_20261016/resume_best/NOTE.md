# 续训窗口验证最佳 27,588 步：失败诊断判断

本轮在查看 test 前固定本次续训窗口 validation 总 loss 最低的 epoch75 / step27588，checkpoint SHA256 为 `e1e579e7bc6bdf64b3c078d6b5414e33630222de989b180ca8f3eb22b59c6ccf`。它不是全程 validation 最佳，全程最佳仍为 1,089 步。输入为规范 CAD 经各自 Encoder 得到的 posterior mean；这是 VAE 重建，不是照片条件重建。

固定 accepted 2,417 件，原始 2,424 件中另有 7 件合同不支持。优化后合法 solid 为 **2,115 / 2,417（87.51%）**。相对 conditioned 基线：救回 51、退步 47、持续失败 255，净增 4。仅拟合合法 1,082 件，高于最后权重的 1,050；优化后两者相同，但成功对象有 38 进、38 出。

## 失败观察

完整覆盖 302 件失败及 51 件救回，共 353 个 ID 的双侧对照。失败中 217 件无向面邻接完全正确。互斥末端为：47 件面未做齐，246 件进入拼接仍非实体，7 件候选实体保存检查失败，2 件保存检查通过但重读不是合法实体。

归一化长度阈值 0.006 下，独立拟合后 293 件、周期替换后 289 件出现边面贴合偏差；273 件两份半边比 GT 更不一致，272 件在选边后仍有端点对不齐，242 件拼接时有自由边。175 件出现过全部候选环闭合并接纳而面仍失败，124 件构面时舍弃部分边界。标签可以重叠，未知保留分母，详见 [REPORT](REPORT.md)。

贴合告警也见于 45 / 51 件救回，不能视为失败充分条件。在 47 件新失败中，“全部闭环仍无法构面”新增 15、消失 0；在 51 件救回中消失 17、新增 2。丢弃边界观察在新失败中新增 19、在救回中消失 14。这定位了与成败变化相伴的裁剪阶段现象，不证明具体损失项或单一几何量是唯一原因。

全部 13 件仅拟合合法、优化后失败对象都完成同 raw 的完整路径对照。原始终态和 STEP DATA 一致，选择后的面、边及连接一致；后续拟合与裁剪也随路径改变，不能把差异全归因于某一优化 loss。

## 研究判断

本权重与最后权重的有效性总数相同，但原始几何、仅拟合成功数及个体成败不同，不能按一个总数判定两者等价。两份权重都完整保留，不用 test 重新选训练 checkpoint。[主评估](../../evaluation_20261016/REPORT.md)同时呈现原始几何分布、所属面对曲线误差、合法 solid 和尾部错误。

当前结果显示多数对象的几何改善还没有转化为稳定的实体有效性收益。下一步若研究结构，应针对边界在所属曲面上的一致性与可裁剪性，而非仅继续追求平均距离下降。本轮只完成评估，不自动改模型或续训。
