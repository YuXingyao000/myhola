# 2026-10-12：局部注意力 intersection 的完整测试

状态：两种输入的 raw、两种后处理全集评估、失败全集诊断及成对对照均已完成，独立审计通过。完整指标见 [REPORT](REPORT.md)，阶段统计见 [失败报告](../failure_census_20261012/REPORT.md)，机制解读见 [失败分析](../failure_census_20261012/NOTE.md)。

## 当前结果不支持替换上一版基线

| 相同后处理协议 | 上一版 refinement | 本版局部注意力 |
|---|---:|---:|
| 仅拟合/裁剪/缝合的合法 solid | 1,062/2,417（43.94%） | 99/2,417（4.10%） |
| 加入几何优化的合法 solid | 2,113/2,417（87.42%） | 482/2,417（19.94%） |

优化后，479 件两版都成功，301 件两版都失败，1,634 件由成功变失败，3 件由失败变成功。本版 1,935 个失败件全部进入诊断，3 件救回单列成功对照；可读 STEP、Compound 或 shell 不视为合法 solid。

在本版相同 raw 输出上，后处理几何优化救回 388 件、让原本成功的 5 件失败，净增 383 个 solid。因此当前整体退步不是“关闭后处理优化就能解决”的问题；只拟合路径本来就仅有 99 件成功。这里指 OCC 前的后处理几何优化，不是网络内部的 refinement block。

2,417 件均已得到后处理终态，本版没有超时；优化后有 1 件 STEP 不可读、682 件原生 STEP 几何测量出错。这些状态并不替代 solid 判据，全部保留分母。两法共同可计算 STEP 几何的交集是 1,698 件，包含非 solid，不能称为共同成功集合。

## 当前权重的原始解码明显退步

同一 2,417 件、逐值相同的 posterior mean latent，面 XYZ MAE 从 0.00202949 到 0.00366735（+80.7%），面平方 CD 从 4.94483e-5 到 1.45136e-4（2.94 倍），边平方 CD 从 7.77208e-5 到 0.00450363（57.95 倍），逐对象宏平均面邻接 F1 从 99.8583% 到 96.7939%。源码公式、上一版逐件结果、latent 内容和冻结 encoder/posterior 已独立核对。

宏平均 F1 不代表整个零件的邻接全对比例。全集面邻接完全正确的件数从 2,321/2,417（96.03%）降至 1,270/2,417（52.54%）。本版 1,935 个失败件中有 837 件邻接全对；其余 1,098 件有多连或漏连（多连 1,016、漏连 528，两者重叠 446）。同样这 1,935 个 ID 在上一版有 1,839 件邻接全对。因此本轮不能描述为“只退化了几何，拓扑基本不变”；连接预测也明显变差。

不是少数极端样本拉高均值：边平方 CD 中位数为上一版的 43.88 倍，2,417 件中只有 1 件改善。按本版误差去掉最大的 25 件，并同时从上一版移除同样 ID，剩余均值仍差 46.41 倍；这个排除仅用于解释，不替换全集主指标。

更关键的对照：两版面邻接都完全正确的 1,268 件，边平方 CD 仍从 5.058e-5 增至 0.0033916（约 67.05 倍），没有一件改善。因此当前退步不能主要用多预测或漏预测面对来解释。它也不证明原始拓扑已完整正确：面邻接正确仍不等于 coedge 环、端点连接或合法裁剪正确。

## 尚不能归因于末期过拟合

验证集 callback 选择 epoch19 / step7260；`last.ckpt` 与选中权重字节相同。训练记录有 20 个 epoch，末三轮验证总 loss 为 0.568104 → 0.536189 → 0.507484，仍在下降。面局部误差和边面贴合项在 epoch12 后回升，分别约 12.8% 和 6.8%，但训练侧面误差也回升，不是足以单独认定整体过拟合的证据。

边局部误差前约 13 轮停在 0.285 附近，之后才明显下降，最后为 0.05129；边 feature 匹配项最后仍为 0.36273。当前证据更支持“这次新 intersection 的训练状态尚未恢复旧 decoder 的能力”，但不能据此保证继续训练会追上，也不能用这一个 checkpoint 否定局部注意力表示。

面误差也广泛退化：面 MAE 仅 16 件改善，面平方 CD 仅 20 件改善。虽然替换的是 intersection，face Transformer、面/边 CNN、bbox、classifier 和 refiner 都参与了本次微调，只有 encoder/posterior 冻结；因此面质量变化并不矛盾。多任务梯度牵制或旧几何能力遗忘只是待验证的解释，本轮没有因果消融。

还有一个必须写清的结构变化：旧 inter 为 hidden512、8层、FFN2048，新 inter 为 hidden128、2层、FFN256。因此本轮同时改变信息来源、容量和初始化，不是同等容量的注意力交换方式消融。新模块随机初始化且所有可训练模块使用同一 2e-5 学习率，已迁移的几何头也同时变化。`edge_feature` 对齐的是冻结 GT edge CNN 的特征，权重1；末轮它占标量总 loss 约71.5%，但这不等于梯度占比。完整源码与曲线解释见 [训练审查](diagnostics/TRAINING_INTERPRETATION.md)。

## 比较范围

固定 diffusion latent 的另一组解码，面平方 CD 为 0.00512925 → 0.00514383，边平方 CD 为 0.0130541 → 0.0160225。该组本身含生成 latent 与 GT 的差异，且没有 GT 面对应，不计算面对应 MAE 或邻接 F1。不能把这一组较小的相对变化解释为新 decoder 在后验重建上的问题已消失，也不能当成重新测试了整个图像条件 diffusion。

本轮只测已固定权重，不按 test 选 checkpoint，不改变后处理或修复预算。研究决策需要结合最终 solid 和阶段诊断；现阶段不把当前模型替换上一版 refinement 基线。

## 完成后的失败诊断

1,935 件失败中，1,246 件终止于裁剪门槛、678 件终止于实体构造、10 件未通过保存检查，1 件阶段未知。阈值0.006下，1,934 件仍有边面贴合偏差（1 件未知）；1,090 件出现某次全部候选环闭合并接纳、仍裁不出面的现象（48 件未知）。这些是可重叠观察，超阈值不等于充分失败条件。837 件面邻接全对的失败对象中仍全部存在贴合偏差，422 件出现上述严格闭环仍裁剪失败。原始几何退步、面连接退步和边界在曲面上的有效性需要共同解释。全部图表及按 ID 的双侧证据见 [交互统计页](../failure_census_20261012/page/index.html)。
