# 本轮结果与研究判断

2026-10-14，固定2417件、验证最佳epoch157/step57354，与原Intersection＋refinement比较。原始推理、两种后处理和完整失败诊断已完成；数值独立复算与页面验证记录随报告保存。

## 主要结果

加入几何优化后，原生合法solid从2113/2417（87.42%）变为2111/2417（87.34%）：43件救回、45件退步、261件持续失败、2068件持续成功。主有效性没有提升；净差2件不支持把本版宣称为更好的有效性模型。不做几何优化时1062→1047，亦未改善。

原始面XYZ MAE下降7.96%，面平方CD均值下降17.87%；面几何收益存在。原始边平方CD均值几乎持平（−0.045%），但中位数增加11.90%，仅981/2417件改善。双方GT面邻接均正确的2306件中，边中位数仍增加10.86%，只924件改善。这支持“本轮典型边几何没有改善”的判断，而不能把差距全部归于少数错连对象。该子集只固定无向面邻接，不等于coedge/wire拓扑完备。

后处理之后有另一层结果：共同可计算2228件的边平方CD均值从0.000348242降至0.000318750，中位数从0.000102473降至0.0000852823。它是修复后几何的改善，不能倒推原始边已达到CAD tolerance，也不能抹去成实体率持平的事实。共同可计算集合包含无效solid，不应称为共同成功子集。

固定旧diffusion latent重放的面CD均值下降0.42%、边CD均值增加0.70%，没有进行新的图片条件采样；不能将本轮描述成照片重建整体提升。

## 均值的两种不同情况

边对GT的平方CD是“均值持平，但中位对象更差”。互反半边差距则相反：均值接近翻倍由少量大异常驱动，其中位数下降6.86%，1554/2417件改善；双方GT邻接均正确子集的互反mean均值下降17.65%。不能只读汇总均值就说全部半边更不一致。详见 [原始分布](diagnostics/RAW_DISTRIBUTION.md) 与 [互反分布](diagnostics/RECIPROCAL.md)。

## 决策边界

以有效solid和原始边精度为本次改造目标，目前没有证据将这个checkpoint作为原refinement的全面替代；同时保留面几何及修复后边几何的正面结果。候选在基线之上额外训练57354步，当前结果不能将正负变化单独归因于条件调制，也不能说明所有面条件几何解码方案都无效。

306件失败中223件原始无向面邻接完全正确，296件周期替换后边面偏差超过0.006；不过43件救回中42件也超限。最终失败面的候选检查还确认20件不同wire相交。完整末端阻断、配对变化、缺测和11件优化退步对照见 [全集fail census](../failure_census_20261014/REPORT.md) 与 [研究判断](../failure_census_20261014/NOTE.md)，不能将这些多标签观察写成互斥根因。

CD为归一化XYZ下的双向平方距离，不是最大边面偏差；本轮没有证明全体误差都低于1e-3或1e-4。两件极端误差的 [具体面对核验](diagnostics/OUTLIER_PAIR_PROBE.md) 显示，正确GT邻接仍可输出位置错误的边，合并点集CD又会弱化边的归属信息。这支持进一步讨论几何一致性约束，但目前没有改模型或新启训练。
