# 本版曲线条件调制与上一版 refinement 对比

本报告比较上一版 Intersection refinement（`intersection`）与本版曲线条件调制（`conditioned`）。原 HoLa 仅用于冻结 encoder 与既有 latent 的来源核验，不是本报告的质量对照。
固定测试 2417 件 CAD；原清单另有 7 件合同不支持样本，仍保留在 2424 的总体分母中。

## 互反半边一致性

两版都显式对称化 logits。单向 pair 为零由该规则保证，不代表学会环闭合。互反曲线 CD 不检查方向，且两版选中 pair 集合可能不同。

| 输入 | 指标 | 可计算（旧/新） | 上一版 refinement | 本版曲线条件调制 |
|---|---|---:|---:|---:|
| Posterior mean | 每件平均互反差距 | 2417/2417 | 6.50885e-05 | 0.000128781 |
| Posterior mean | 每件最差互反差距的均值 | 2417/2417 | 0.000887942 | 0.00320896 |
| Posterior mean | 每件单向 pair 数 | 2417/2417 | 0 | 0 |
| 归档 latent | 每件平均互反差距 | 2417/2417 | 0.000287048 | 0.000269625 |
| 归档 latent | 每件最差互反差距的均值 | 2417/2417 | 0.00360071 | 0.00410553 |
| 归档 latent | 每件单向 pair 数 | 2417/2417 | 0 | 0 |

**均值需要结合分布阅读。** posterior 每件平均互反差距的中位数为 2.39559e-05 → 2.23136e-05；同 ID 改善 1554/2417 件（64.29%）。候选误差最高的 25 件占候选互反总误差的 74.16%、全部正增量的 96.49%；从双方同时移除这些 ID 后，均值比为 0.8640。
因此这里的均值上升主要受少数尾部对象推动，不能读成多数对象的互反一致性变差；全体均值仍保留为主结果。
双方 GT 面邻接均全对的 2306 件中，平均互反差距的均值比为 0.8235。中位数、P90/P95、尾部和完整邻接子集见 [互反差距诊断](diagnostics/RECIPROCAL.md)。

具体 face pair、两方向曲线、GT 对应边及所属面距离见 [两个极端案例核验](diagnostics/OUTLIER_PAIR_PROBE.md)。案例不能代表全体，也不隔离新增模块与训练曝光的因果作用。


## 来源与限制

上一版 raw/STEP/终态为只读复用，经过 split、输入 raw SHA、全部后处理算法、预算、采样与状态协议审核。其耗时来自历史运行，不能与本次直接视为受控速度对比。STEP SHA 本次补记，不伪称存在历史 STEP 哈希证明。
本版曲线条件调制、额外微调及权重选择共同决定本次差异，不能只归因于单一 block；边面距离超阈值也是相关信号，不自动构成唯一根因。失败全集及救回/退步的成对诊断见 [失败统计](../failure_census_20261014/REPORT.md)。
