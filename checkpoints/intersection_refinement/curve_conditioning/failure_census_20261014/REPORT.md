# 曲线条件调制：与上一版 refinement 的失败对照

本版失败306件：持续失败261件，退步45件；另有43件救回。固定2417件中合法实体由2113变为2111。
失败件中，原始无向面连接完全正确有223件。某次全部候选环均闭合并接纳，面仍裁不出来有167件；该项未知0件。
阈值0.006下，本版失败件中296件在周期替换后仍观察到边面贴合偏差（未知0件）；救回组也有42/43件出现该观察。超阈值不是失败的充分条件。
本版存在11件fit-only成功而优化后失败，均纳入完整路径对照；比较的是整体路径，不是某个loss的因果消融。

## 来源与解释边界

复用已有intersection诊断326件，新增baseline对照23件；来源资产检查5517个，变化0个。

- 主分母只含本版失败；救回对照按结果选择，不代表全部成功件。接受集2417，原始2424中7件合同不支持。
- 同一ID的观察变化不等于因果改善；任何一侧未知都不算标签消失。多标签可以重叠，不能相加为失败总数。
- 只在原终态、STEP DATA精确一致且没有观测错误时采用阶段轨迹；缺测保留原分母。
- 边面距离是固定采样的归一化XYZ长度，不是毫米、Hausdorff距离或可裁剪性的证明。
- 面级错误只统计最终失败的decoder面；候选自身与所属上下文去重合并，OCC错误码不是唯一根因。
- 本次额外微调曝光与上一版不同，无法把全部收益或退步因果归于曲线条件调制；不代表端到端照片重建结果。
- 原HoLa的50件3D图库只作历史参考，页面不将其视作本版几何。
