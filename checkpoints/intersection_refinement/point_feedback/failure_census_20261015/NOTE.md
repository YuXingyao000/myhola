# 逐点曲线反馈：失败全集的结果与边界

2026-10-15。候选为验证最佳 epoch34 / step12705，直接 baseline 为此前曲线条件调制 epoch157 / step57354。固定2417件、相同输入与后处理协议；额外训练曝光与新模块同时变化，以下是当前 checkpoint 的比较，不是等预算架构因果消融。完整数值见 [REPORT](REPORT.md)、[紧凑统计](compact_summary.json)，整体几何和历史第三版比较见 [评估记录](../evaluation_20261015/NOTE.md)。

## 完整性与最终结果

原生合法solid由2111/2417（87.34%）变为2104/2417（87.05%），减少7件、0.29个百分点。持续失败256件、退步57件、救回50件、持续成功2054件。候选313失败加50救回共363件全部做了双侧诊断；baseline复用321件经过身份、协议及资产核验的历史 conditioned 记录，另外42件补齐重放，没有把intersection记录改名复用。

363条候选轨迹及相同ID的363条baseline轨迹全部复现原终态和STEP DATA，观测工具终态错误0；5665项来源资产变化0。轨迹完整不代表所有派生几何观察均可确定，未知仍留在原分母。

## 高频现象仍然集中在几何协调

在归一化长度阈值0.006下，313失败中，独立拟合后边面贴合偏差305件，周期替换后仍有300件；选边后端点不齐276件（未知4），孪生半边超过GT差异273件（未知10），缝合仍有自由边251件。229件的原始无向面连接完全正确，但这不等于完整半边结构或可裁剪性正确。

“优化后的面离GT更远”有310件，“优化后的边离GT更远”有301件。这里的优化是生产后处理的几何优化，不是网络中的refinement。这两项只要求对应误差变化大于1e-12，并不要求超过0.006，也不代表变化幅度很大；0.006只作用于相应的距离阈值项。该观察记录相对GT的变化，不能单凭其高频就认定优化整体有害或确定精度根因。

高频距离告警也存在于成功对照：50件救回中，44件仍有周期替换后的边面贴合超阈值。故不能把300/313解释为300件已证明由同一个投影误差导致失败；这是一项接近饱和的对象级多标签。

## 成败变化更直接表现在裁剪与缝合路径

313失败的互斥末端阻断为：缺面未进入实体拼接50件；进入拼接仍未得到实体255件；候选solid未通过保存检查7件；保存检查通过但重读不是合法solid1件。

有174件观察到某次尝试中全部候选环都闭合并被接纳，面仍未构建成功。退步57件中，这个现象新出现29件、消失2件；救回50件中消失17件、新出现2件。缝合自由边在退步组新出现46件、消失2件，在救回组消失38件、没有新出现。相比单个距离阈值是否超限，这些阶段证据更直接对应本轮成败切换，但仍不能代替几何原因的因果证明。

最终失败的decoder面共496个，其中308个完成候选检查、185个没有候选可检查、3个未知。方向无法一致确定、curve-on-surface／same-parameter及闭合性检查错误可共现；没有候选不是检查通过，OCC错误码也不是唯一UV根因。

## 优化路径对照与精度阈值

本轮有19件fit-only合法而optimized失败，全部完成双路径重放。两侧raw完全相同，选择后的面、边和连接数组也完全相同；差异发生在后续优化及其引起的拟合、裁剪与缝合路径。该对照不把整个后处理路径变化归因于某一个loss。fit-only的19份upstream记录为partial，原因是该路径没有optimized阶段几何，相关观察保留未知；这不改变已确认的路径重放和数组一致性。

拟合曲线/曲面偏离输入点在0.006下分别为0/13件，但降到0.002后为14/69件。因而不能从较宽阈值下的低频推断拟合精度已足够满足1e-3或1e-4目标。边面距离也只是固定采样的归一化长度，不是毫米、Hausdorff误差或CAD容差保证。

## 本轮判断

当前逐点反馈没有提升固定全集合法solid比例；50件救回与57件退步说明它确实改变了后续几何路径，而尚未稳定地把局部改善转为整体有效性收益。完整原始几何分布须与本统计一起判断，不能只用总loss或失败组的单个高频标签决定架构去留。
