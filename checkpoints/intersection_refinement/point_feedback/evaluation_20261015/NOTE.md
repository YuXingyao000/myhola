# 结果与研究判断

2026-10-15（Asia/Shanghai）。本轮唯一候选为验证最佳epoch34／step12705，直接基线为conditioned epoch157／step57354。原始推理、两种raw指标、两条后处理和全集fail census均已完成；313件失败与50件救回均取得双侧精确重放一致的诊断。

## 有效性没有提升，几何收益与退步并存

固定2417件，优化后原生合法solid为2111→2104（87.34%→87.05%），50件救回、57件新增失败、256件持续失败、2054件持续成功。仅拟合为1047→1048，基本持平。历史原refinement为2113件有效，本轮相对它52件救回、61件退步。7件合同不支持样本继续在原2424总体分母中单列。

原始面XYZ MAE下降7.51%，面平方CD均值下降10.12%。边平方CD均值上升12.97%，但中位数下降7.55%，1441/2417件改善；双方GT面邻接均全对的2306件中，边CD均值下降3.30%。因此不能说典型边普遍更差，也不能删掉尾部后宣称全体改善。候选误差最大25件占其边总误差44.57%，从双方同时排除这些ID仅作敏感性分析时，剩余均值下降6.81%。

互反半边平均差距的中位数下降15.18%，1821/2417件改善；全体均值下降62.29%含少量旧极端对象的贡献。在双方邻接全对集合里，该均值只下降2.67%，且每件最差互反差距的均值反而上升30.82%。两方向更接近，不等于边界位于正确位置或所有边均被预测。

优化后共同可计算2211件的边平方CD均值从0.000322268升到0.000393717，中位数从0.0000854755降到0.0000835380；该集合不是共同有效solid子集。最终几何也有长尾退步，不能只引用中位数作为全面改善结论。

两个optimized对象测量超时，其中一个已确认原生有效solid并保留在有效数里；没有重试筛选成功结果。完整计数见 [REPORT](REPORT.md)。

## 全集失败仍集中在边界几何与实体构建

313件失败的末端阻断为：50件面没做齐，255件进入拼接但没有solid，7件候选solid未通过保存检查，1件保存后重读不合法。这是互斥的终态分类，不是根因分类。原始无向面邻接全对仍失败的有229件；57件新增失败中49件邻接全对。这里的邻接正确不等于半边、wire及顶点拓扑完整正确。

归一化长度阈值0.006下，独立拟合后边面不贴合305件，周期替换后仍不贴合300件；选边后端点不齐276件（另4件未知），互反半边不一致273件（另10件未知），拼接时有free edge 251件。174件某次全部候选环都闭合并接纳后，面仍裁不出来。以上是可重叠观察，不能相加。优化后面／边更远离GT分别310／301件只要求误差增加>1e-12，并不表示增加幅度超过0.006，不能凭频率认定优化总体有害。

50件救回中44件也有周期替换后边面不贴合超阈值，说明这一对象级告警不足以区别成功与失败。同ID比较中，57件退步有29件新出现“全部环闭合仍裁剪失败”、20件新出现“做出面但舍弃部分边界”；50件救回分别有17／16件消除了这两种观察。这些阶段变化比单独提高贴合告警计数更有区分力，仍不是因果证据。

最终失败面候选检查中，37件观察到自相交wire，25件观察到不同wire相交（分别另有56／67件无法完整判定，且标签可重叠）。这与用户描述的环相交现象相关，但尚不能认定这些对象都是同心圆漂移，也不能把OCC错误码当作唯一UV根因。

另有19件本轮fit-only成功、optimized失败，同raw及选边后数组均一致、两条完整路径重放一致；整体上optimized仍从1048提高到2104件，因此不能用这19件否定几何优化。详见 [全集失败报告](../failure_census_20261015/REPORT.md) 与 [离线页面](../failure_census_20261015/page/standalone.html)。

## 两个具体反例

`00335203` 是候选原始边CD最高对象：本轮漏掉GT面对(0,6)，边CD从0.000327524升到0.0344956，其中GT→预测覆盖误差为0.0342885。留下来的互反曲线更一致，也无法弥补缺失整条边。

`00326127` 两版GT面邻接都全对；本轮某半边对自身面对GT曲线的平方CD为0.209372，但到任意GT边的单向均方距离仅0.000737785。其整体边CD反而改善。这表明合并点集CD会弱化边的归属错误，邻接全对也不保证几何边界正确。两件只用于解释指标盲区，不能推广为全体唯一原因。详情见 [面对核验](diagnostics/OUTLIER_PAIR_PROBE.md)。

同一次完整推理中捕获末端反馈的共同输入／输出，进一步确认：`00326127` 的错误半边在进入新模块前，自身GT平方CD已经是0.2093712，反馈后0.2093719，本次坐标修正平均约1.735e-5；严重错位不是本次末端修正首次造成。`00335203` 缺失面对的存在概率为0.1782805，末端坐标模块没有改变存在性或导出集合的通路。两件所有预测面、bbox、方向、refiner特征及分类结果均保持不变。此处只定位当前推理阶段，不能排除新增模块在训练中通过梯度影响其他decoder参数。见 [末端反馈前后](diagnostics/FEEDBACK_BRANCH_PROBE.md)。

## 决策边界

当前没有证据将本轮checkpoint升级为更高有效性的默认版本。面几何、典型边几何和互反一致性的收益值得记录，同时保留长尾与最终solid未改善的事实。训练既更新旧decoder也更新新反馈，且额外增加12705步曝光，不把所有变化单独归因于新增模块。

研究判断：下一步更值得解释“面对连接正确时，属于该面对的曲线为何仍定位错误或破坏wire”，而不是从本轮数据直接归咎encoder压缩或增加邻接classifier容量。合并点集平均CD、对象平均贴合以及互反一致性都可能掩盖一条关键边的错误；面与边的归属、每条边的尾部误差和环的相对位置应成为后续表示／目标设计的明确职责。这是方向假设，尚未据此修改结构或训练目标。

固定归档diffusion latent重放的面CD均值下降0.16%、边CD上升0.22%，没有新采样图片条件模型，也不能据此声称真实照片重建能力提升。全部CD为归一化坐标下平方距离，不证明每条边的最大误差低于1e-3或1e-4。
