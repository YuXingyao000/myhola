# Task

对 Intersection refinement 首次测试的全部失败件精准溯源并统计，使用通俗中文报告和统计页面，为下一轮架构讨论提供可复核证据。先冻结协议，再扩展诊断工具；不训练、不修改模型或后处理决策。

# Assumptions

数据：主集合是 evaluation_20261011 / intersection / posterior_mean / optimized 的 304 个 native-invalid-solid；固定 accepted 2417，原始 2424 中合同不支持的 7 件另列。面 latent 去重未执行，面身份与 GT 顺序一致；半边选择确实执行，二者不可混称去重。GT 仅用于离线溯源。

边界：以已有几何和拓扑观测定位错误最早出现及持续阻断阶段，不把相关性、BRepCheck 名称或距离超阈值当成唯一已证明根因。只有原 STEP DATA 相等且诊断完整的重放，才用于原运行阶段归因。未能进一步分清的原因明确保留未知。

实施：旧 369 件完整溯源可覆盖原失败→新失败 262 件及原失败→新成功 107 件。核对原始资产/生产算法/测量合同后只读复用，并保留原指纹；旧 runner 的方法名扩展与生产算法变化分开审计。本任务无需用户补充信息。

- 新比较：checkpoints/intersection_refinement/evaluation_20261011；验证固定 epoch10 / step3993，权重与 latent 来源沿用已完成评估。
- 旧比较：checkpoints/joint_boundary/comparison_20261011。
- 旧溯源：checkpoints/joint_boundary/legacy_failure_census_20261011。
- GT：/mnt/d/data/deepcad_v7；清单 checkpoints/joint_boundary/validation/test_contract_audit/accepted.txt，SHA256 2864849e8240134c6033cc6cd64efa19337f67fea94b89a493690ae84355b7b3。
- 新侧共检查 411 件：304 失败 + 107 救回对照；旧侧补充 42 个原成功、新失败的对照。全体 2417 的既有 raw/validity 统计用于总体对照。
- 新版 fit-only 成功、optimized 失败的 6 件单独追加 fit-only 重放，比较相同输入的整体优化路径，不归因到单个 loss。

# Outputs

本目录保存冻结清单、资产与协议审计、完整阶段轨迹/几何、逐件多标签、分组统计、成对变化、中文报告、静态统计图及可筛选统计页面。大体积诊断留本地；计划、工具、紧凑结果与页面源码受 Git 管理。全部写 checkpoints，不写 experiments。

# Processing Protocol

1. 从 raw/post/fit 表严格读取显式 native_valid_solid 布尔值，核对相同 2417 IDs、终态及来源哈希。主失败304分为262持续失败与42新增失败；救回107单列，不能混入失败分母。
2. 显式 method 合同扩展已有诊断调度，保持 legacy 旧接口兼容，不将 intersection 标成 legacy。保留生产 post 源码和决策不变。
3. 对411新输出、42旧对照重放相同 CPU seed/drop_num=0/optimized名义200自适应600路径，逐对象隔离、180秒上限。记录 raw、半边选择、优化、独立拟合/周期替换、候选闭环/裁剪、缝合、保存与重读阶段。
4. 对6件优化退步补充 fit-only。各重放与对应原 STEP DATA 做精确哈希比较；重放偏离、诊断错误或缺测留在原分母，阶段标签设未知，不改变原成功/失败结论。
5. 用同一测量定义计算 raw pair FP/FN、同方向重复、互反半边偏差、选择删除正确pair、异常曲线/面接近、端点闭合代理、GT几何漂移、拟合与边面贴合残差、原STEP自由边。阈值为归一化长度 .002/.006/.01/.08，保留敏感性；不是毫米。
6. 汇总最终仍失败的面与最终返回面实际丢弃的边界；修复中一度失败后来成功的尝试分开。若已有记录支持，补充独立拟合与周期曲线替换后的贴合变化，以及同一个失败面的上下文错误，但不将错误名升级为唯一根因。
7. 对相同对象比较旧新观测，分别报告262持续失败、42退步、107救回。成功对照明确标记成功，不能被失败专用末端分类误标为未知。总体失败集369→304的频次变化只作描述，成对变化用于更精确地定位。

# Metrics

- 主304件各机制的确认正例/确认阴性/未知，多标签可重叠；最早可观察异常和最终阻断分开。
- 直接阻断：无可用闭环；有闭环仍裁剪失败；返回面但丢边界；所有面返回却未成solid；保存/重读分歧。
- 上游与阶段证据：面数、连接FP/FN/重复、半边选择损失、曲线/面/端点接近、边贴两面残差、优化前后保真与目标变化、自由边未共享。
- 匹配cohort的几何连续值与阈值标签变化；面级共现分母及成功对照保持明确。
- 6件 fit→optimized 退步的完整路径对照、原输入/选择相等与 STEP 重放一致性。

# Decision Rule

研究方向依照重复出现的具体阻断、上游可定位证据和成对变化提出；不把所有失败强制分成互斥根因。优先解释“边没围住”“闭合但裁不出面”“面边对不上”“边界被丢掉”“面没拼成实体”等直白现象，同时链接准确判据。不能据此直接证明 latent 不平滑、容量不足、反馈块因果贡献或端到端照片效果。

# Edge Cases

空预测、非有限值、缺GT/资产、来源不一致、对应缺失、未知bool、超时、崩溃、重放分歧均显式记录。几何采样超时与已有solid有效性分开；已确认成功不抹去。正常互反半边不算重复；薄壁附近的边不自动认定需要焊合；丢wire不自动认定丢孔；未知不计为改善或阴性。

# Validation / Sanity Checks

工具扩展检查方法名、身份集合/分组守恒、布尔未知、固定分母、未知传播、成功对照分类和协议拒绝混用。真实少量端到端重放验证无 instrumentation error、STEP DATA一致后执行全集。最终核对主304/新411/旧42/优化对照6完整性、来源前后哈希、统计可重算以及页面图表与JSON一致。

# Implementation Constraints

复用已有测量，不重写生产几何算法；修改调度/字段访问不得改变随机状态、数组次序、阈值和OCC调用。现有baseline输出只读，重放写独立目录；历史合同/指纹不能重标成当前运行。相关检查完成后执行固定全集，不用小样本替代结论。图表采用标准绘图库，页面只呈现已有统计，不新增50件以外的3D图库。

# Deliverables

可复现命令、全集失败原因统计、旧新成对溯源、6件优化路径退步说明、通俗中文报告与统计页面/图表、精确判据与未知项、简短Git提交。根据实际结果提出有证据的下一步方向，记录任何未完成/无法确认的部分。
