# How to use these quality references

These images demonstrate the quality of mature materials, construction details,
relationships between objects, and coherent illumination. Inspect the visible
evidence at room, activity, and surface scales.

The requested room type, activity, and layout come from the user brief. A quality
reference may depict a different kind of place. Do not inherit its room layout,
camera positions, or object inventory as requirements for the new scene.

No base project or source scene is supplied. Build an independent environment
from suitable individual assets and authored construction. Do not locate or
import the project behind the reference images. Judge the result by the brief
and comparable visual quality, not by similarity to the reference composition.
