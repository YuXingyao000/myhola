# Baseline Outputs

This folder stores reproducible baseline and two-step outputs for the current
DeepCAD v7 real-photo cube24 protocol.

- `diffusion_baseline_real_v7_cube24/`: no-topology real-photo diffusion baseline.
- `cvae_visibility_topology_cache/`: 06-18 CVAE predicted topology matrices.
- `cvae_visibility_diffusion_outputs/`: two-step CVAE-topology + diffusion predictions.
- `cvae_visibility_diffusion_post/`: post-processed STEP files and evaluation results.
