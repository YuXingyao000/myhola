# 选取候选区域

读取 scene_context 中的对象索引和 views；查看所附原图及同分辨率编号图。
寻找最多 max_regions 个不同的可拍摄区域，例如工作台、桌面或地面。候选可以被少量
可移动物件占用，不只寻找已经很空的角落。不要把同一个落点换几个机位算成多个区域。

每个候选给出唯一 region_id、真实支撑对象 ID、参考 view_id、原图中的矩形像素范围
[left, top, right, bottom] 和选择理由。范围圈出支撑区域，不是把整幅照片框起来；
后续工具会射向该支撑网格测量，不能根据照片猜测厘米数。没有合适位置可返回空列表。

列出该区域附近完整的 movable_groups：id、members、support_object_id、reason。
这份名单确定本次候选的可移动范围；它只是语义判断，之后工具仍要测量原/新位置支撑。
无需移动的区域可以为空。对象 ID 使用索引中的完整名称，数字仅供图片定位。
